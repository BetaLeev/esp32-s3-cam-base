# 音频模块引脚配置

## 硬件概述

| 项目 | 配置 |
|------|------|
| 音频DAC芯片 | MAX98357 (I2S输入 D类放大器) |
| I2S控制器 | ESP32-S3 I2S_NUM_0 |
| 通信协议 | I2S (Philips标准) |
| 数据格式 | 16bit Stereo |
| 采样率 | 44.1kHz (CD音质) |

## 引脚定义

### I2S 接口

| 功能 | GPIO | 说明 |
|------|------|------|
| BCLK (位时钟) | GPIO2 | I2S Bit Clock |
| WS (字选择/LRC) | GPIO21 | I2S Word Select (Left/Right Clock) |
| DIN (数据输入) | GPIO47 | I2S Serial Data Input |

### 控制引脚

| 功能 | GPIO | 说明 |
|------|------|------|
| SD (Shutdown) | GPIO46 | MAX98357使能，高电平有效 |
| GAIN (增益控制) | GPIO0 | 高电平=9dB，低电平=6dB |

## 引脚分配原理图

```

                        ┌─────────────────────┐
                        │                     │

```

## 引脚选择依据

### 为什么选择这些GPIO？

GPIO选择原则：**选择完全空闲的GPIO，避免与其他外设冲突**

| GPIO | 其他外设 | 状态 |
|------|---------|------|
| GPIO0 | 电机AIN1 | 空闲 |
| GPIO2 | - | 空闲 (原GPIO4被摄像头占用) |
| GPIO21 | - | 空闲 |
| GPIO46 | I2C SDA | 空闲 |
| GPIO47 | - | 空闲 |

### 不可用的GPIO

| GPIO范围 | 原因 |
|---------|------|
| GPIO35-37 | PSRAM引脚，不可使用 |
| GPIO38-40 | TF卡引脚，已被占用 |
| GPIO4-18 | 摄像头接口，已被占用 |
| GPIO41 | I2C SCL，已被占用 |
| GPIO22 | 舵机，已被占用 |

## 增益配置

MAX98357的GAIN引脚控制输出增益：

| GAIN电平 | 增益(dB) | 说明 |
|---------|---------|------|
| 高 (GPIO0=1) | 9dB | 默认配置 |
| 低 (GPIO0=0) | 6dB | 低功率模式 |

> **注意**: 标准接法是 SEL 引脚接地，此时 GAIN 高=9dB，GAIN 低=6dB

## 软件配置

引脚配置定义在 [`hw_audio.h`](hw_audio.h)：

```c
// I2S 接口
#define GPIO_AUDIO_BCLK       2    // 位时钟
#define GPIO_AUDIO_WS         21   // 字选择
#define GPIO_AUDIO_DIN        47   // 数据输入

// 控制引脚
#define GPIO_AUDIO_SD         46   // 关闭控制
#define AUDIO_DEFAULT_GAIN    0    // 增益 (GPIO0)

// I2S 参数
#define AUDIO_I2S_NUM             I2S_NUM_0
#define AUDIO_DEFAULT_SAMPLE_RATE 44100
```

## 初始化流程

```c
// 使用默认引脚初始化
esp_err_t ret = audio_i2s_init_default();
// 或指定引脚初始化
ret = audio_i2s_init(GPIO2, GPIO21, GPIO47);
```

初始化会自动：
1. 配置GPIO为I2S功能
2. 设置GPIO46为输出并拉高（使能MAX98357）
3. 设置GPIO0为输出并设置默认增益(9dB)
4. 启用I2S通道

## 常见问题

### Q: 音频无声怎么办？
1. 检查GPIO46是否为高电平（SD引脚）
2. 检查GPIO0增益设置
3. 确认WAV文件格式正确（44.1kHz 16bit stereo）
4. 检查扬声器连接

### Q: 如何切换到其他GPIO？
修改 `hw_audio.h` 中的宏定义，然后确保新GPIO未被其他外设占用。

### Q: 支持哪些音频格式？
当前版本支持：WAV (44.1kHz 16bit stereo)
需要ESP-ADF支持更多格式：MP3, AAC, FLAC, OPUS等
